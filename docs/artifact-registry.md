# Реестр аналитики и артефактов ИИ

Этот файл учитывает аналитику, сводки, индексы, таблицы, извлечённые данные и другие производные материалы по корпусу книг про мышонка Тима.

Перед добавлением или изменением файлов прочитайте `../AGENTS.md`.

Исходный корпус находится в `../origin/`. Новые сказки следует хранить отдельно в `../generated/`.

## Как добавлять артефакты

Для каждого нового или существенно изменённого файла добавьте или обновите строку в таблице выше. Одновременно внесите запись в журнал изменений `../AGENTS.md`.
