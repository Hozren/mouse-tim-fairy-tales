# Выборочная сборка и публикация книг

Обновлено: 2026-11-25. Автор: Аркан. Источники: `.github/workflows/build-stories.yml`, `.github/scripts/detect_changed_stories.py`, репозиторные сборщики.

## Детекция

На push ветки сравниваются before/after; на pull request — merge-base и head. Новая или изменённая директория `generated/<story-slug>/` создаёт отдельный matrix job. Удаления файлов внутри существующей сказки тоже учитываются; удалённые целиком сказки и файлы непосредственно в `generated/` не собираются. Новая сказка должна иметь финальный `book.json`.

Неизменённые сказки не пересобираются. Изменения общей документации, сборщиков и workflow сами по себе не запускают сборку сказок. Ручной `workflow_dispatch` и push тега `books-*` собирают все сказки.

## Результат без ZIP

Каждый job собирает и проверяет `_dist/<story-slug>/<story-slug>.epub` и `.pdf`. Мастер-PNG остаются в Git, публикации используют компактные JPEG-производные (1100 px, качество 76). Локальный `_dist/` игнорируется Git.

При push в default branch, ручном запуске на ней или теге `books-*` каждая выбранная сказка получает отдельный GitHub Release `story-<slug>-<полный SHA коммита>` с двумя отдельными assets: EPUB и PDF. Это прямые файлы без дополнительного ZIP и без срока хранения Actions artifacts. Новая сказка автоматически получает свой релиз; изменение существующей — новую версию. Предыдущие версии и неизменённые сказки остаются нетронутыми. Повторный запуск того же коммита обновляет те же два assets.

Релиз создаётся черновиком и публикуется только после загрузки обоих файлов. Автоматические релизные теги `story-*` не запускают повторную сборку. Общий latest не назначается, поскольку релизы относятся к разным сказкам. Встроенные GitHub ссылки Source code (zip/tar.gz) могут отображаться отдельно; это не сборки книг, workflow их не загружает.

PR и сторонние ветки только собирают и проверяют, ничего не публикуют. Права верхнего уровня — `contents: read`, у build job — `contents: write` для Releases; fork PR сохраняет ограничения GitHub. Архивные Actions artifacts больше не создаются.
