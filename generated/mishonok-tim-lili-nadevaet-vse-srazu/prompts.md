# Промпты и производственные заметки

Use case: illustration-story.

Все изображения создаются встроенным imagegen. Для согласованности персонажей сначала создаётся `character-anchor.png`; затем он используется как главный визуальный референс для обложки и всех сцен. Опубликованные иллюстрации из `origin/` используются только как ориентир по общим свойствам детской книжной графики; новые композиции и изображения должны быть оригинальными.

Общие ограничения для каждой сцены: сохранять дизайн персонажей, пропорции, одежду и палитру; выразительные, но добрые эмоции; без печатного текста, букв, логотипов и водяных знаков; без фотореализма и 3D; не добавлять лишних персонажей; не унижать Лили визуально — комизм должен быть тёплым.

Индивидуальные сцены перечислены в `scene-plan.md`. Полные фактически использованные промпты фиксируются в `image-manifest.md` после генерации.
